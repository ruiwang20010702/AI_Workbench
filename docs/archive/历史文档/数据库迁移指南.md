# 数据库迁移指南

## 添加 Projects 表的 Progress 列

### 问题描述

在测试数据生成过程中，您可能会看到以下警告：

```
Error updating project progress: {
  code: 'PGRST204',
  message: "Could not find the 'progress' column of 'projects' in the schema cache"
}
```

这是因为 `projects` 表缺少 `progress` 列，该列用于存储项目的完成进度（0-100%）。

### 解决方案

#### 方法 1: 使用 Supabase Dashboard（推荐）

1. 登录 Supabase Dashboard
2. 进入项目的 **SQL Editor**
3. 复制并执行以下 SQL：

```sql
-- 为 projects 表添加 progress 列
ALTER TABLE projects 
ADD COLUMN IF NOT EXISTS progress NUMERIC(5,2) DEFAULT 0;

-- 添加列注释
COMMENT ON COLUMN projects.progress IS '项目进度百分比 (0-100)';

-- 验证列是否添加成功
SELECT column_name, data_type, column_default 
FROM information_schema.columns 
WHERE table_name = 'projects' AND column_name = 'progress';
```

4. 重启应用服务器

#### 方法 2: 使用数据库客户端

如果您使用 PostgreSQL 客户端（如 pgAdmin, DBeaver, psql 等）：

1. 连接到数据库
2. 执行上述 SQL 语句
3. 重启应用服务器

#### 方法 3: 使用迁移脚本

我们已经准备好了迁移脚本：

```bash
# 进入 server 目录
cd server

# 执行迁移脚本
npx ts-node src/scripts/run-add-progress-column.ts
```

注意：该脚本可能需要特定的数据库权限，如果失败请使用方法 1 或 2。

### 验证

执行完 SQL 后，您可以验证列是否添加成功：

```sql
-- 查看 projects 表结构
\d projects

-- 或者
SELECT column_name, data_type, column_default, is_nullable
FROM information_schema.columns
WHERE table_name = 'projects'
ORDER BY ordinal_position;
```

您应该看到：
```
column_name | data_type | column_default | is_nullable
------------|-----------|----------------|------------
progress    | numeric   | 0              | YES
```

### 更新现有项目的进度

添加列后，可以运行以下脚本来更新所有现有项目的进度：

```typescript
// 在 server 目录下执行
npx ts-node -e "
import { ProjectProgressUpdater } from './src/models/ProjectProgressUpdater';
ProjectProgressUpdater.updateAllProjectsProgress()
  .then(() => console.log('✅ 所有项目进度已更新'))
  .catch(err => console.error('❌ 更新失败:', err));
"
```

或者手动执行 SQL：

```sql
-- 更新所有项目的进度
WITH project_stats AS (
  SELECT 
    p.id,
    COUNT(t.id) as total_tasks,
    COUNT(CASE WHEN t.status = 'completed' THEN 1 END) as completed_tasks
  FROM projects p
  LEFT JOIN tasks t ON t.project_id = p.id
  GROUP BY p.id
)
UPDATE projects
SET progress = CASE 
  WHEN ps.total_tasks = 0 THEN 0
  ELSE ROUND((ps.completed_tasks::numeric / ps.total_tasks::numeric) * 100, 2)
END
FROM project_stats ps
WHERE projects.id = ps.id;

-- 查看更新结果
SELECT name, progress FROM projects ORDER BY progress DESC LIMIT 10;
```

### 功能说明

添加 `progress` 列后，系统将自动：

1. **任务创建时**: 更新项目进度
2. **任务状态变更时**: 重新计算项目进度
3. **任务删除时**: 更新项目进度

进度计算公式：
```
progress = (已完成任务数 / 总任务数) × 100
```

如果项目没有任务，进度为 0。

### 临时解决方案

如果您暂时不想添加该列，系统会继续正常工作，只是：
- 不会自动计算项目进度
- 会在日志中看到警告信息（不影响功能）
- 前端可能无法显示项目进度条

代码已经做了容错处理，所以不会影响其他功能。

## 其他可选迁移

### 添加项目颜色字段

如果需要为项目添加颜色标识：

```sql
ALTER TABLE projects 
ADD COLUMN IF NOT EXISTS color VARCHAR(20) DEFAULT '#3b82f6';

COMMENT ON COLUMN projects.color IS '项目标识颜色';
```

### 添加项目封面图片

如果需要为项目添加封面图：

```sql
ALTER TABLE projects 
ADD COLUMN IF NOT EXISTS cover_image TEXT;

COMMENT ON COLUMN projects.cover_image IS '项目封面图片URL';
```

### 添加项目归档功能

如果需要归档功能：

```sql
ALTER TABLE projects 
ADD COLUMN IF NOT EXISTS is_archived BOOLEAN DEFAULT FALSE;

CREATE INDEX idx_projects_archived ON projects(is_archived);

COMMENT ON COLUMN projects.is_archived IS '是否归档';
```

## 故障排查

### 问题 1: 权限不足

**错误信息**:
```
permission denied for table projects
```

**解决方法**:
- 确保使用的数据库用户有 ALTER TABLE 权限
- 在 Supabase Dashboard 中使用 SQL Editor 执行（自动使用管理员权限）
- 或联系数据库管理员

### 问题 2: 列已存在

**错误信息**:
```
column "progress" of relation "projects" already exists
```

**解决方法**:
- 这说明列已经存在，不需要再次添加
- 检查列的类型是否正确：
```sql
SELECT data_type FROM information_schema.columns 
WHERE table_name = 'projects' AND column_name = 'progress';
```

### 问题 3: 应用仍然报错

**可能原因**:
- Supabase 缓存未刷新
- 应用服务器未重启

**解决方法**:
1. 在 Supabase Dashboard 中刷新 Schema Cache
2. 重启应用服务器：
```bash
# 停止服务器 (Ctrl+C)
# 然后重新启动
npm run dev
```
