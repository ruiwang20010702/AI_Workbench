## ⚠️ 注意事项

### 1. Progress 列警告

在数据生成过程中会看到以下警告：
```
Could not find the 'progress' column of 'projects' in the schema cache
```

这是正常的，不影响数据创建。只是项目的进度字段没有自动更新。

### 2. 如何修复 Progress 功能

如果需要启用项目进度自动更新功能，请手动在数据库中执行：

```sql
ALTER TABLE projects ADD COLUMN IF NOT EXISTS progress NUMERIC(5,2) DEFAULT 0;
COMMENT ON COLUMN projects.progress IS '项目进度百分比 (0-100)';
```

然后重启应用即可。

### 3. 重新生成数据

如果需要重新生成测试数据，运行：

```bash
cd server
npx ts-node src/scripts/seed-project-data.ts
```

注意：这会**添加**新数据，而不是替换现有数据。如果需要清空数据，请先手动删除或使用数据库管理工具。
