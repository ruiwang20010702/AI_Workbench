## ⚠️ 注意事项

### 1. Progress 列警告

在数据生成过程中，您可能看到了关于 `progress` 列的警告。这不影响数据创建，只是项目进度无法自动计算。

**如何修复**:

参考 [数据库迁移指南](./数据库迁移指南.md)，在数据库中执行：

```sql
ALTER TABLE projects ADD COLUMN IF NOT EXISTS progress NUMERIC(5,2) DEFAULT 0;
```

然后重启应用即可。

### 2. 数据持久化

生成的数据已保存到数据库，不会丢失。您可以：
- ✅ 正常使用这些数据
- ✅ 编辑项目和任务
- ✅ 添加新的项目和任务
- ✅ 删除不需要的数据

### 3. 重新生成

如果需要重新生成测试数据：

```bash
cd server
npx ts-node src/scripts/seed-project-data.ts
```

注意：这会**添加**新数据，不会删除现有数据。

### 4. 清理数据

如果需要清理测试数据，可以：

**方法 1: 手动删除**
- 在前端界面中逐个删除项目

**方法 2: 数据库操作**
```sql
-- ⚠️ 危险操作：删除所有数据
DELETE FROM tasks WHERE creator_id = '12f21e7c-a87c-4c9a-a4e7-30489ace45fa';
DELETE FROM projects WHERE owner_id = '12f21e7c-a87c-4c9a-a4e7-30489ace45fa';
```

**方法 3: 保留部分数据**
```sql
-- 只删除测试项目（根据项目名称）
DELETE FROM projects 
WHERE owner_id = '12f21e7c-a87c-4c9a-a4e7-30489ace45fa'
AND name IN (
  '企业级协同办公平台',
  '移动电商App',
  'AI智能客服系统',
  '企业数据分析平台',
  '工业物联网监控系统',
  '内部开发工具集'
);
```
