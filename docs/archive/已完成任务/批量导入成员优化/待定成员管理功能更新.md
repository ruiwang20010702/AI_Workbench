# 待定成员管理功能更新

## 🎉 更新概览

**更新日期：** 2025-11-01  
**功能：** 现有成员管理现在支持**待定成员**的查看、修改和删除

## ✨ 新增功能

### 1. 统一成员管理界面

现在"现有成员管理"区域可以同时显示：
- ✅ **已确认成员**：已注册并加入项目的用户
- ✅ **待定成员**：已邀请但尚未注册的邮箱

### 2. 待定成员标识

待定成员会显示明显的标识：
- 🟠 **橙色"待定"标签**：在成员名称旁边
- 📧 **仅显示邮箱**：因为用户尚未注册

### 3. 统计信息优化

顶部统计信息现在分别显示：
- 🟢 **X 已确认**：已注册成员数量
- 🟠 **X 待定**：待定成员数量

### 4. 完整操作支持

对待定成员支持所有操作：
- ✅ 修改角色（管理员/成员/观察者）
- ✅ 删除成员
- ✅ 恢复误删

## 🔧 技术实现

### 数据结构更新

```typescript
interface MemberChange {
  memberId: string;
  userId?: string;           // 待定成员没有 userId
  email: string;
  displayName: string;
  originalRole: 'admin' | 'member' | 'observer';
  newRole: 'admin' | 'member' | 'observer';
  action: 'keep' | 'update' | 'remove';
  isPending: boolean;        // 🆕 是否为待定成员
}
```

### 加载逻辑

```typescript
// 1. 加载已确认成员
const confirmedMembers = await projectService.getProjectMembers(projectId);

// 2. 加载待定成员
const pendingMembers = await projectService.getPendingMembers(projectId);

// 3. 合并显示（待定成员排在后面）
setExistingMembers([...confirmedMembers, ...pendingMembers]);
```

### 提交逻辑

```typescript
// 区分已确认成员和待定成员的操作

// 更新角色
if (member.isPending) {
  // 待定成员：先删除再添加（因为没有直接更新 API）
  await deletePendingMember(memberId);
  await batchAddPendingMembers([{ email, role: newRole }]);
} else {
  // 已确认成员：直接更新
  await updateProjectMember(memberId, { role: newRole });
}

// 删除成员
if (member.isPending) {
  await deletePendingMember(memberId);
} else {
  await removeProjectMember(memberId);
}
```

## 🎯 使用场景

### 场景 1：清理未注册的邀请

**问题：** 邀请了很多人，但有些邮箱错误或不会注册  
**解决：** 在"现有成员管理"中找到待定成员，直接删除

### 场景 2：调整待定成员的角色

**问题：** 邀请时给错了角色，但用户还没注册  
**解决：** 在"现有成员管理"中修改待定成员角色，无需重新邀请

### 场景 3：统一管理所有成员

**问题：** 需要在多个地方管理已确认成员和待定成员  
**解决：** 现在统一在"现有成员管理"中操作

## 🐛 常见问题

### Q1: 看不到待定成员？

**原因：** 项目没有待定成员  
**解决：** 在"添加新成员"中输入未注册的邮箱，提交后会创建待定成员

### Q2: 待定成员没有"待定"标签？

**原因：** 浏览器缓存  
**解决：** 按 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows) 强制刷新

### Q3: 修改待定成员角色后，重新打开还是原来的角色？

**原因：** 提交失败或 API 错误  
**解决：** 
1. 打开浏览器控制台（F12）
2. 查看 Network 标签
3. 找到失败的请求
4. 查看错误信息

### Q4: 删除待定成员后，成员还在列表中？

**原因：** 删除 API 调用失败  
**解决：** 
1. 检查控制台错误日志
2. 确认后端 API 正常
3. 重新尝试删除

## 📝 API 说明

### 获取待定成员

```typescript
GET /api/projects/:projectId/pending-members

Response:
{
  pending_members: [
    {
      id: "pending-member-id",
      email: "user@example.com",
      role: "member",
      created_at: "2025-11-01T00:00:00Z"
    }
  ]
}
```

### 删除待定成员

```typescript
DELETE /api/projects/:projectId/pending-members/:memberId

Response: 204 No Content
```

### 批量添加待定成员

```typescript
POST /api/projects/:projectId/pending-members/batch

Request:
{
  members: [
    { email: "user@example.com", role: "member" }
  ]
}

Response:
{
  added_count: 1,
  skipped: []
}
```
