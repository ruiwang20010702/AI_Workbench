# 🚀 快速验证指南

## 一分钟快速测试

### 准备工作（10秒）

1. **确保服务运行**
   ```bash
   # 检查后端
   curl http://localhost:5001/health
   
   # 检查前端
   curl http://localhost:5173
   ```

2. **刷新浏览器**
   - 按 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows)

---

### 核心功能验证（50秒）

#### ✅ 测试 1: 查看现有成员（10秒）

1. 登录系统
2. 找到任意项目，点击"编辑"按钮
3. 进入"团队协作"步骤（Step 3）

**预期：** 看到"现有成员管理"区域，显示成员列表

---

#### ✅ 测试 2: 修改角色（10秒）

1. 在成员列表中选择一个成员
2. 点击角色下拉框，选择不同角色

**预期：** 
- 卡片背景变为**黄色**
- 显示"角色已修改"标签
- 底部显示"1 个角色变更"

---

#### ✅ 测试 3: 删除成员（10秒）

1. 点击成员右侧的垃圾桶图标

**预期：**
- 卡片背景变为**红色**
- 姓名显示删除线
- 显示"待删除"标签
- 底部显示"1 个待删除"

---

#### ✅ 测试 4: 恢复成员（10秒）

1. 点击刚才删除成员的恢复按钮（绿色加号）

**预期：**
- 卡片恢复正常
- 删除线消失
- "待删除"标签消失

---

#### ✅ 测试 5: 提交变更（10秒）

1. 修改一个成员角色
2. 点击"保存更改"
3. 等待提交完成

**预期：**
- 提交成功
- 弹窗关闭
- 项目列表刷新

---

- [ ] 删除/恢复按钮

## 🐛 快速问题排查

### 看不到"现有成员管理"？
➡️ 确保是**编辑模式**，不是创建模式

### 成员列表一直显示"加载中..."？
➡️ 打开控制台（F12），检查 API 请求是否成功

### 点击按钮无反应？
➡️ 打开控制台，查看是否有 JavaScript 错误

### 提交后变更未生效？
➡️ 检查控制台的网络请求，查看后端返回
