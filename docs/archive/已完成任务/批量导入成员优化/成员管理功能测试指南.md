# 成员管理功能测试指南

## 📋 功能概述

在项目编辑模式下，现在可以：
1. ✅ 查看所有现有成员
2. ✅ 修改成员角色（管理员/成员/观察者）
3. ✅ 删除成员
4. ✅ 恢复误删的成员
5. ✅ 批量添加新成员

---

## 🎯 测试步骤

### 准备工作

1. **确保服务运行**
   - 后端：`http://localhost:5001`
   - 前端：`http://localhost:5173`

2. **刷新浏览器**
   - 按 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows)
   - 清除缓存并重新加载

---

### 测试 1: 查看现有成员

**步骤：**
1. 登录系统
2. 找到任意已有项目
3. 点击项目卡片上的"编辑"按钮（铅笔图标）
4. 进入"团队协作"步骤（Step 3）

**预期结果：**
- 看到"现有成员管理"区域
- 显示所有项目成员列表
- 每个成员显示：
  - 头像（首字母）
  - 姓名
  - 邮箱
  - 当前角色（下拉选择器）
  - 删除按钮（垃圾桶图标）

---

### 测试 2: 修改成员角色

**步骤：**
1. 在现有成员列表中找到任意成员
2. 点击角色下拉选择器
3. 选择不同的角色（例如：从"成员"改为"管理员"）

**预期结果：**
- 成员卡片背景变为**黄色**
- 显示"角色已修改"标签
- 底部统计显示"1 个角色变更"

**提交测试：**
1. 点击"保存更改"按钮
2. 等待提交完成
3. 重新打开项目编辑页面
4. 确认角色已更新

---

### 测试 3: 删除成员

**步骤：**
1. 在现有成员列表中找到任意成员
2. 点击右侧的删除按钮（垃圾桶图标）

**预期结果：**
- 成员卡片背景变为**红色**
- 成员姓名显示删除线
- 显示"待删除"标签
- 删除按钮变为恢复按钮（绿色加号）
- 底部统计显示"1 个待删除"

**提交测试：**
1. 点击"保存更改"按钮
2. 等待提交完成
3. 重新打开项目详情页面
4. 确认成员已被移除

---

### 测试 4: 恢复误删成员

**步骤：**
1. 先标记一个成员为删除（参考测试 3）
2. 点击恢复按钮（绿色加号图标）

**预期结果：**
- 成员卡片恢复正常背景（白色）
- 删除线消失
- "待删除"标签消失
- 恢复按钮变回删除按钮
- 底部统计中"待删除"数量减少

---

### 测试 5: 批量添加新成员

**步骤：**
1. 在"添加新成员 - 批量导入"文本框中输入邮箱
2. 输入测试数据：
   ```
   admin@localhost
   test@example.com
   newuser@example.com
   ```
3. 点击文本框外部（失去焦点）

**预期结果：**
- 显示"正在检查邮箱状态..."
- 邮箱按状态分类显示：
  - ✅ **已注册用户**（绿色）：`admin@localhost`, `test@example.com`
  - 📧 **未注册邮箱**（橙色）：`newuser@example.com`
  - ⚠️ **已是项目成员**（灰色）：如果某些邮箱已是成员

**提交测试：**
1. 点击"保存更改"
2. 等待提交完成
3. 重新打开项目详情页面
4. 确认新成员已添加

---

### 测试 6: 组合操作

**步骤：**
1. 修改 2 个成员的角色
2. 删除 1 个成员
3. 添加 3 个新成员邮箱

**预期结果：**
- 底部统计显示：
  - "2 个角色变更"
  - "1 个待删除"
- 批量导入区域显示"3 个成员"

**提交测试：**
1. 点击"保存更改"
2. 观察控制台输出（F12 开发者工具）
3. 应该看到类似：`成功处理 3 个成员变更`
4. 重新打开项目，确认所有变更生效

## 🐛 常见问题排查

### 问题 1: 看不到"现有成员管理"区域

**原因：** 只有在编辑模式下才显示
**解决：** 确保是点击"编辑"按钮，而不是"创建项目"

### 问题 2: 成员列表显示"加载中..."一直不消失

**原因：** API 请求失败
**解决：**
1. 打开浏览器控制台（F12）
2. 查看 Network 标签
3. 检查 `/api/projects/:id/members` 请求是否成功

### 问题 3: 提交后变更未生效

**原因：** 后端 API 调用失败
**解决：**
1. 打开浏览器控制台
2. 查看是否有错误信息
3. 检查后端日志

### 问题 4: 删除按钮点击无反应

**原因：** JavaScript 错误
**解决：**
1. 打开浏览器控制台
2. 查看是否有 JavaScript 错误
3. 刷新页面重试
