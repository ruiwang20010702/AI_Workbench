### 已实现功能

✅ **查看所有成员** - 同时显示已确认成员和待定成员 🆕

## 🚀 快速测试（1分钟）

### 步骤

1. **刷新浏览器**
   - 按 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows)

2. **打开项目编辑**
   - 登录系统
   - 找到任意项目，点击"编辑"
   - 进入"团队协作"步骤（Step 3）

3. **验证功能**
   - 查看"现有成员管理"区域
   - 修改一个成员角色（背景变黄色）
   - 删除一个成员（背景变红色）
   - 恢复删除的成员（背景恢复正常）

4. **提交测试**
   - 点击"保存更改"
   - 等待提交完成
   - 重新打开项目，确认变更生效

## 🐛 快速问题排查

| 问题 | 解决方案 |
|------|----------|
| 看不到"现有成员管理"区域 | 确保是**编辑模式**，不是创建模式 |
| 成员列表一直加载中 | 打开控制台（F12），检查 API 请求 |
| 点击按钮无反应 | 打开控制台，查看 JavaScript 错误 |
| 提交后变更未生效 | 检查控制台网络请求和后端日志 |

## 📊 技术实现

### 修改的文件

- `client/src/components/projects/ProjectCreateModal.tsx`

### 核心数据结构

```typescript
interface MemberChange {
  memberId: string;
  userId: string;
  email: string;
  displayName: string;
  originalRole: 'admin' | 'member' | 'observer';
  newRole: 'admin' | 'member' | 'observer';
  action: 'keep' | 'update' | 'remove';
}
```

### 核心函数

- `loadExistingMembers` - 加载现有成员
- `handleMemberRoleChange` - 修改角色
- `handleMemberRemove` - 删除成员
- `handleMemberRestore` - 恢复成员
- `processMemberChanges` - 批量处理变更
