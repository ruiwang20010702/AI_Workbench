## 项目上下文分析

### 技术栈架构
**前端技术栈**:
- React 18 + TypeScript
- Vite 构建工具
- Tailwind CSS 样式框架
- Lucide React 图标库
- React Router 路由管理
- Axios HTTP客户端

**后端技术栈**:
- Node.js + Express.js
- TypeScript
- PostgreSQL 主数据库
- Redis 缓存和会话存储
- JWT 身份认证
- OpenAI API 集成

**部署架构**:
- Docker 容器化
- Docker Compose 多容器编排
- Nginx 反向代理
- 支持生产环境部署
