## 📦 7 个函数列表

| 函数名 | 用途 | 使用场景 |
|--------|------|----------|
| `match_notes` | 向量相似度搜索 | AI 智能推荐、相关笔记查找 |
| `get_todo_stats` | 待办统计 | 仪表板、完成率分析 |
| `get_project_stats` | 项目统计 | 项目进度、成员协作分析 |
| `get_user_activity_stats` | 用户活动统计 | 用户活跃度、周报生成 |
| `search_notes` | 混合搜索 | 智能搜索、全文+语义搜索 |
| `update_all_search_vectors` | 批量更新搜索向量 | 数据迁移、索引重建 |
| `get_recent_notes` | 获取最近笔记 | 最近浏览、快速访问 |

---

## 🧪 测试示例

```sql
-- 1. 获取待办统计
SELECT * FROM get_todo_stats('YOUR_USER_ID');

-- 2. 获取最近 7 天活动
SELECT * FROM get_user_activity_stats('YOUR_USER_ID', 7);

-- 3. 搜索笔记
SELECT * FROM search_notes('关键词', NULL, 'YOUR_USER_ID', 10);

-- 4. 获取最近笔记
SELECT * FROM get_recent_notes('YOUR_USER_ID', 5);
```
