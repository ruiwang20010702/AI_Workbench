# 项目管理功能完善 - 共识文档

## 任务目标
完善项目管理功能的UI交互，使E2E测试能够通过，并提供完整的项目查看、编辑、删除功能。

## 明确的需求描述

### 1. 修复弹窗可访问性属性
- 为 `ProjectCreateModal` 添加 `role="dialog"` 和 `aria-modal="true"` 属性
- 为弹窗标题添加 `id="modal-title"` 和 `aria-labelledby` 关联

### 2. 创建项目卡片组件
创建 `ProjectCard.tsx` 组件，包含：
- 项目名称和描述
- 项目状态和优先级标签
- 项目进度条
- 开始和结束日期
- 团队成员数和任务统计
- 更多操作按钮（⋮）和下拉菜单
  - 查看详情
  - 编辑项目
  - 删除项目

### 3. 创建项目详情查看弹窗
创建 `ProjectDetailModal.tsx` 组件，包含：
- 项目完整信息展示
- 项目统计数据
- 项目成员列表
- 项目任务概览
- 操作按钮（编辑、关闭）

### 4. 集成到项目主页面
在 `ProjectsPage.tsx` 的仪表盘视图中：
- 在统计卡片下方添加项目网格
- 使用 `ProjectCard` 组件渲染项目列表
- 处理查看详情、编辑、删除的交互

## 技术实现方案

### 组件结构
```
client/src/components/projects/
  ├── ProjectCard.tsx          # 新增：项目卡片组件
  ├── ProjectDetailModal.tsx   # 新增：项目详情弹窗
  ├── ProjectCreateModal.tsx   # 修改：添加可访问性属性
  └── ... (其他现有组件)

client/src/pages/
  └── ProjectsPage.tsx         # 修改：集成项目卡片网格
```

### 技术约束
- 使用 React + TypeScript
- 使用 Tailwind CSS 样式
- 使用 lucide-react 图标库
- 遵循现有代码风格和命名约定
- 支持无障碍访问（ARIA属性）

### 集成方案
1. 项目卡片将显示在仪表盘视图的统计卡片下方
2. 使用网格布局（响应式：1列 → 2列 → 3列）
3. 保持与现有组件的样式一致
4. 复用现有的 `projectService` API 方法

## 技术约束和集成方案确认

### 样式约束
- 使用 Tailwind CSS 类名
- 颜色方案与现有组件保持一致
- 间距使用 Tailwind 标准单位（4、6、8等）

### 交互约束
- 弹窗背景点击关闭（添加 `onClick` 处理）
- ESC 键关闭弹窗（添加 `onKeyDown` 处理）
- 下拉菜单点击外部关闭（使用 `useEffect` + `addEventListener`）

### 数据流约束
- 使用现有的 `projectService` 进行API调用
- 状态管理使用 React Hooks（`useState`, `useEffect`）
- 错误处理使用 `try-catch` + `console.error`
