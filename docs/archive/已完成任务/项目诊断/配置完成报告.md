
## 💡 重要提示

### 环境变量安全
- ⚠️ **永远不要**提交 `.env` 文件到 Git
- ⚠️ **永远不要**在代码中硬编码密钥
- ⚠️ **永远不要**在日志中打印密钥
- ✅ **必须使用**环境变量存储敏感信息
- ✅ **必须为**不同环境使用不同的密钥

### API 密钥管理
- Supabase Service Role Key 拥有完全数据库权限，**绝不能**暴露给客户端
- SiliconFlow API Key 有使用额度限制，注意监控用量
- JWT Secret 泄露会导致所有 Token 失效，需立即更换

### 数据库初始化
- 必须按顺序执行 SQL 脚本（基础表 → 项目表 → 周报表）
- 执行前备份数据库（生产环境）
- 检查表是否创建成功（执行验证查询）
