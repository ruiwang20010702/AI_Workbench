## 📋 环境变量配置

### 服务端环境变量 (`server/.env`)

#### 🔴 必需配置（应用无法启动）
- [ ] `SUPABASE_URL` - Supabase 项目 URL
- [ ] `SUPABASE_ANON_KEY` - Supabase Anon 密钥
- [ ] `SUPABASE_SERVICE_ROLE_KEY` - Supabase 服务角色密钥
- [ ] `SILICONFLOW_API_KEY` - SiliconFlow AI API 密钥
- [ ] `JWT_SECRET` - JWT 签名密钥（至少 32 位随机字符串）

#### 🟡 推荐配置（影响功能）
- [ ] `PORT` - 服务器端口（默认 5000）
- [ ] `NODE_ENV` - 运行环境（development/production）
- [ ] `CORS_ORIGIN` - 允许的前端域名
- [ ] `SILICONFLOW_API_BASE_URL` - API 基础 URL

#### 🟢 可选配置（增强功能）
- [ ] `OPENAI_API_KEY` - OpenAI 备用 API
- [ ] `GITHUB_TOKEN` - GitHub API Token（周报 Git 统计）
- [ ] `GITHUB_USERNAME` - GitHub 用户名
- [ ] `GITHUB_REPOSITORIES` - 监控的仓库列表
- [ ] `AI_ANALYZE_API_KEY` - 外部 AI 分析服务

### 前端环境变量 (`client/.env`)

- [ ] `VITE_API_URL` - 后端 API 地址（默认 http://localhost:5000/api）
