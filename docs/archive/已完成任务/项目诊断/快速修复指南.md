# AI Workbench 快速修复指南

**目标**: 15 分钟内让项目正常运行

## 🎯 修复步骤

### 步骤 1: 配置环境变量（5分钟）

```bash
# 1. 复制环境变量模板
cp .env.example server/.env
cp client/.env.example client/.env

# 2. 编辑服务端配置
open server/.env
# 或者使用你喜欢的编辑器
# vim server/.env
# code server/.env
```

**必填项**（应用无法启动）：
```bash
# 在 server/.env 中填写：
SUPABASE_URL=https://xxxx.supabase.co          # ⚠️ 必填
SUPABASE_ANON_KEY=eyJxxx...                    # ⚠️ 必填
SUPABASE_SERVICE_ROLE_KEY=eyJxxx...            # ⚠️ 必填
SILICONFLOW_API_KEY=sk-xxx                     # ⚠️ 必填（AI功能）
JWT_SECRET=                                     # ⚠️ 必填（生成方式见下方）
```

**生成 JWT Secret**:
```bash
# macOS/Linux
openssl rand -hex 64

# 或使用 Node.js
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"

# 将生成的字符串填入 JWT_SECRET
```

**可选项**（不影响启动）：
```bash
OPENAI_API_KEY=sk-xxx                          # 可选
GITHUB_TOKEN=ghp_xxx                           # 可选（周报Git统计）
```

### 步骤 2: 获取必需的 API 密钥（10分钟）

#### 2.1 Supabase 配置

1. **注册/登录 Supabase**
   - 访问: https://supabase.com
   - 使用 GitHub 账号登录

2. **创建项目**
   - 点击 "New Project"
   - 项目名称: `ai-workbench`
   - 数据库密码: 设置一个强密码（保存好）
   - 区域: 选择距离最近的（如 Tokyo）
   - 等待 1-2 分钟创建完成

3. **获取配置信息**
   - 进入项目后，点击左侧 "Settings" → "API"
   - 复制以下信息：
     - `Project URL` → `SUPABASE_URL`
     - `anon` `public` → `SUPABASE_ANON_KEY`
     - `service_role` `secret` → `SUPABASE_SERVICE_ROLE_KEY`

#### 2.2 SiliconFlow API 密钥

1. **注册 SiliconFlow**
   - 访问: https://siliconflow.cn
   - 注册账号（支持手机号或邮箱）

2. **获取 API Key**
   - 登录后进入控制台
   - 点击 "API 密钥" → "创建新密钥"
   - 复制密钥 → `SILICONFLOW_API_KEY`

3. **充值（可选）**
   - 新用户通常有免费额度
   - 如需更多额度可以充值

## 🐛 常见问题排查

### 问题 1: 后端启动失败 - 数据库连接错误

**错误信息**:
```
Supabase config missing in production runtime
或
Failed to connect to database
```

**解决方案**:
1. 检查 `server/.env` 中的 Supabase 配置
2. 确认 `SUPABASE_URL` 格式正确（https://xxx.supabase.co）
3. 确认 `SUPABASE_SERVICE_ROLE_KEY` 不是 anon key
4. 重启服务

### 问题 2: 前端无法连接后端

**错误信息**:
```
Network Error
或
ERR_CONNECTION_REFUSED
```

**解决方案**:
1. 确认后端已启动在 5000 端口
2. 检查 `client/.env` 中的 `VITE_API_URL`
3. 确认没有防火墙阻止
4. 刷新前端页面

### 问题 3: AI 功能不可用

**错误信息**:
```
AI 服务不可用
或
401 Unauthorized
```

**解决方案**:
1. 检查 `SILICONFLOW_API_KEY` 是否正确
2. 确认 API Key 有余额
3. 查看后端日志确认错误详情

### 问题 4: 编译错误

**错误信息**:
```
Cannot find module 'mustache'
或
TypeScript compilation errors
```

**解决方案**:
```bash
# 清理并重新安装
cd server
rm -rf node_modules package-lock.json
npm install

# 重新编译
npm run build
```

### 问题 5: 周报功能报错

**错误信息**:
```
Table 'weekly_reports' does not exist
```

**解决方案**:
```bash
# 执行数据库迁移脚本
# 在 Supabase Dashboard 的 SQL Editor 中运行：
# server/database/create-weekly-reports-tables.sql
```
