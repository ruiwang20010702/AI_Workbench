## 🎯 新增功能详解

### 1. 在线预览功能 ✨

**支持格式**:
- ✅ PDF 文件：使用 react-pdf 或 @react-pdf-viewer
- ✅ 图片文件：JPG, PNG, GIF, WEBP
- ⚠️ Office 文件：提示下载，不支持预览

**用户体验**:
```
点击文档 → 弹出预览窗口 → 查看内容 → 可直接下载
```

**技术实现**:
- 前端：PDF.js 渲染引擎
- 后端：新增预览 API (`/documents/:id/preview`)
- 支持缩放、翻页 (PDF)

---

### 2. 版本管理功能 📚

**核心能力**:
- ✅ 自动版本追踪：同名文件上传自动创建新版本
- ✅ 版本历史：查看所有历史版本
- ✅ 版本恢复：将旧版本恢复为最新版本
- ✅ 版本对比：显示上传者、时间、大小

**版本规则**:
```
需求文档.pdf (版本 1) → 用户上传同名文件 → 需求文档.pdf (版本 2)
                       → 旧版本标记为历史版本
                       → 新版本标记为最新版本
```

**数据库设计**:
- `version`: 版本号 (1, 2, 3...)
- `parent_document_id`: 父版本 ID
- `is_latest`: 是否最新版本

---

### 3. 拖拽上传功能 🎨

**用户体验**:
```
┌─────────────────────────────┐
│  📁 拖拽文件到此处上传      │
│  或点击选择文件             │
│  ─────────────────────────  │
│  支持 PDF, DOC, 图片等      │
│  最大 20MB，支持多文件      │
└─────────────────────────────┘
```

**交互反馈**:
- 拖拽进入：边框高亮 (蓝色)
- 拖拽离开：恢复正常
- 释放文件：开始上传
- 上传中：进度条显示

**技术实现**:
- HTML5 Drag & Drop API
- 支持单个/多个文件
- 文件验证 (类型/大小)

---

### 4. 项目创建时上传 🚀

**使用场景**:
用户在创建项目时，就可以上传相关文档，一次性准备好所有资料。

**实现流程**:
```
1. 用户创建项目
2. 填写项目信息
3. 上传文档 (临时存储)
4. 点击"创建"按钮
5. 后端创建项目
6. 将临时文件关联到项目
7. 完成
```

**技术实现**:
- 临时上传 API: `POST /api/uploads/temp`
- 文件暂存在 `uploads/temp/` 目录
- 项目创建成功后移动到正式目录
- 关联 API: `POST /api/projects/:id/documents/attach`

**UI 位置**:
在 `CreateProjectModal` 中添加"项目文档"部分。

## 🗂️ 数据库变更

### 新增字段

```sql
ALTER TABLE project_documents
ADD COLUMN file_path VARCHAR(500) NOT NULL DEFAULT '',
ADD COLUMN file_size INTEGER NOT NULL DEFAULT 0,
ADD COLUMN mime_type VARCHAR(100) NOT NULL DEFAULT '',
ADD COLUMN version INTEGER NOT NULL DEFAULT 1,
ADD COLUMN parent_document_id UUID REFERENCES project_documents(id) ON DELETE SET NULL,
ADD COLUMN is_latest BOOLEAN DEFAULT TRUE;

CREATE INDEX idx_project_documents_parent ON project_documents(parent_document_id);
```

### 影响评估
- ✅ 向后兼容：新字段有默认值
- ✅ 数据安全：不会影响现有数据
- ✅ 性能优化：添加了索引
