# 文档上传功能调试指南

## 🔍 问题现象

页面显示"暂无文档"，但用户表示已经上传了文件。

## 📋 排查步骤

### 步骤1: 检查浏览器控制台

**操作**:
1. 打开浏览器（推荐 Chrome）
2. 按 `F12` 或 右键 → "检查"
3. 切换到 **Console** 标签

**查看**:
- 是否有红色错误信息？
- 是否有网络请求失败？

**常见错误**:
```
❌ Error: Request failed with status code 403
   → 权限问题：用户不是项目成员

❌ Error: Request failed with status code 401
   → 认证问题：Token 过期，需要重新登录

❌ Error: Request failed with status code 500
   → 服务器错误：查看后端日志
```

---

### 步骤2: 检查网络请求

**操作**:
1. 在开发者工具中切换到 **Network** 标签
2. 刷新页面或重新上传文件
3. 找到相关请求

**关键请求**:

#### 2.1 上传请求
```
POST /api/projects/{projectId}/documents
```

**查看**:
- Status: 应该是 `201 Created`
- Response: 应该返回文档对象
```json
{
  "success": true,
  "data": {
    "id": "xxx",
    "title": "文件名.pdf",
    "file_path": "/uploads/projects/xxx/文件名.pdf",
    ...
  }
}
```

#### 2.2 获取文档列表
```
GET /api/projects/{projectId}/documents?latestOnly=true
```

**查看**:
- Status: 应该是 `200 OK`
- Response: 应该返回文档数组
```json
{
  "success": true,
  "data": [
    { "id": "xxx", "title": "文件名.pdf", ... }
  ]
}
```

**如果返回空数组 `[]`**:
- 说明数据库中确实没有数据
- 上传可能失败了，但前端没有报错

### 步骤4: 验证用户权限

**问题**: 用户可能不是项目成员，导致上传失败

**验证脚本**:
```bash
cd /Users/ruiwang/Desktop/AI_Workbench/server
npx ts-node -e "
import { supabaseAdmin } from './src/config/database';

async function checkPermission() {
  const projectId = 'YOUR_PROJECT_ID'; // 替换为实际项目ID
  const userId = 'YOUR_USER_ID';       // 替换为实际用户ID
  
  console.log('检查权限...');
  console.log('项目ID:', projectId);
  console.log('用户ID:', userId);
  
  // 检查是否是项目成员
  const { data: member } = await supabaseAdmin
    .from('project_members')
    .select('role')
    .eq('project_id', projectId)
    .eq('user_id', userId)
    .single();
  
  if (member) {
    console.log('✅ 是项目成员，角色:', member.role);
  } else {
    console.log('❌ 不是项目成员');
    
    // 检查是否是项目所有者
    const { data: project } = await supabaseAdmin
      .from('projects')
      .select('owner_id')
      .eq('id', projectId)
      .single();
    
    if (project && project.owner_id === userId) {
      console.log('✅ 是项目所有者');
    } else {
      console.log('❌ 也不是项目所有者');
    }
  }
  
  process.exit(0);
}

checkPermission();
"
```

## 🎯 可能的问题和解决方案

### 问题1: 权限不足

**症状**: 
- Network 返回 `403 Forbidden`
- 错误信息: "您不是项目成员"

**解决方案**:
1. 确认你登录的用户
2. 确认该用户是项目成员或项目所有者
3. 添加用户到项目:
   - 在项目详情页点击"成员管理"
   - 添加用户邮箱

---

### 问题2: Token 过期

**症状**:
- Network 返回 `401 Unauthorized`
- 错误信息: "请先登录"

**解决方案**:
1. 重新登录
2. 刷新页面

---

### 问题3: 数据库迁移未完成

**症状**:
- Network 返回 `500 Internal Server Error`
- 后端日志: "column does not exist"

**解决方案**:
```bash
cd /Users/ruiwang/Desktop/AI_Workbench/server
npx ts-node src/scripts/run-migrate-documents.ts
```

---

### 问题4: 文件保存失败

**症状**:
- 上传时显示成功，但没有创建文档记录
- 后端日志: "文件保存失败"

**解决方案**:
```bash
cd /Users/ruiwang/Desktop/AI_Workbench/server
mkdir -p uploads/temp uploads/projects
chmod -R 755 uploads
```

---

### 问题5: 前端缓存问题

**症状**:
- API 返回数据，但页面不显示

**解决方案**:
1. 硬刷新: `Ctrl+Shift+R` (Windows) 或 `Cmd+Shift+R` (Mac)
2. 清除浏览器缓存
3. 切换到其他标签再切换回来
