## 🎉 项目概述

成功实现了一个完整的项目文档管理系统，包括前后端完整功能：文件上传（拖拽/点击）、文件下载、在线预览（PDF/图片）、版本管理、权限控制、临时文件支持等。

### 核心特性

✅ **文件上传**
- 支持拖拽和点击上传
- 多文件同时上传
- 文件类型和大小验证（20MB）
- 支持 11 种文件类型（PDF、Office、图片）
- 实时上传进度显示

✅ **文件管理**
- 文件列表展示（名称、大小、创建者、时间）
- 文件下载
- 文件删除（需权限）
- 文件图标自动识别

✅ **在线预览**

- 图片文件在线预览
- 缩放、旋转功能
- 分页浏览（PDF）
- 全屏预览模式

✅ **版本管理**
- 同名文件自动创建新版本
- 版本历史查看
- 版本恢复功能
- 版本比较（大小、创建者、时间）

✅ **权限控制**
- 基于项目成员角色的权限
- 上传权限（admin/member）
- 删除权限（admin/member）
- 观察者只读权限

✅ **临时文件**

- 临时文件自动清理

## 🔌 API 接口

### 已实现的 9 个 API 接口

#### 1. 上传文档
```
POST /api/projects/:id/documents
Content-Type: multipart/form-data
Body: file (文件)

Response: {
  success: true,
  data: Document
}
```

#### 2. 获取文档列表
```
GET /api/projects/:id/documents?latestOnly=true

Response: {
  success: true,
  data: Document[]
}
```

#### 3. 下载文档
```
GET /api/projects/:id/documents/:docId/download

Response: File Binary
```

#### 4. 预览文档
```
GET /api/projects/:id/documents/:docId/preview?token=xxx

Response: File Binary
```

#### 5. 删除文档
```
DELETE /api/projects/:id/documents/:docId

Response: {
  success: true,
  message: "文档删除成功"
}
```

#### 6. 获取版本列表
```
GET /api/projects/:id/documents/:docId/versions

Response: {
  success: true,
  data: DocumentVersion[]
}
```

#### 7. 恢复版本
```
POST /api/projects/:id/documents/:docId/restore
Body: {
  versionId: string
}

Response: {
  success: true,
  data: Document
}
```

#### 8. 临时上传
```
POST /api/uploads/temp
Content-Type: multipart/form-data
Body: file (文件)

Response: {
  success: true,
  data: TempFile
}
```

#### 9. 关联临时文件
```
POST /api/projects/:id/documents/attach
Body: {
  temp_ids: string[]
}

Response: {
  success: true,
  message: "文件关联成功"
}
```

## ⚠️ 注意事项

### 1. 文件大小限制
- 单个文件最大 20MB
- 超过限制会被前后端同时拒绝

### 2. 文件类型限制
- PDF: `application/pdf`
- Word: `application/msword`, `.docx`
- Excel: `.xls`, `.xlsx`
- PowerPoint: `.ppt`, `.pptx`
- 图片: `image/jpeg`, `image/png`, `image/gif`, `image/webp`

### 3. 版本管理
- 同名文件会自动创建新版本
- 版本恢复会创建新版本（不会覆盖）
- 删除文档会删除所有版本

### 4. 临时文件
- 临时文件会在 24 小时后自动清理
- 项目创建模式不支持临时上传（提示用户先创建项目）

### 5. 预览功能
- 仅支持 PDF 和图片预览
- 其他文件类型只能下载
