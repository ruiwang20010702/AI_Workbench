# AI应用功能使用指南

## 功能概述

AI助手现在提供两项全新的智能分析功能，帮助您更好地管理笔记和待办事项：

1. **智能推荐** - 基于您的使用习惯，智能推荐需要关注的待办事项和相关笔记
2. **预测分析** - 分析您的任务完成趋势，预测未来工作负荷

## 访问方式

1. 登录系统后，点击导航栏的"AI助手"菜单
2. 或直接访问：http://localhost:5173/ai-assistant（开发环境）

## 智能推荐功能

### 功能说明
智能推荐会根据以下因素为您推荐最需要关注的内容：
- 📌 **高频标签**：您最常使用的标签相关内容
- ⏰ **到期时间**：即将到期的待办事项
- 🎯 **优先级**：高优先级的任务
- 📝 **最近笔记**：与您当前工作相关的笔记

### 使用步骤

1. **选择工具**
   - 在AI助手页面顶部工具栏中，点击"智能推荐"按钮（灯泡图标）

2. **获取推荐**
   - 点击页面底部的"获取智能推荐"按钮
   - 系统将分析您的数据并生成推荐

3. **查看推荐依据**
   - 页面顶部会显示蓝色信息卡片
   - 包含：高频标签、笔记数量、待办事项数量
   - 帮助您了解推荐的来源

4. **浏览推荐列表**
   - 每个推荐项显示：
     - 📌 类型标签（待办/笔记）
     - 📝 标题
     - 💡 推荐理由
     - 🎯 优先级（高/中/低）
     - 📅 到期时间（如有）

5. **刷新推荐**
   - 点击右上角的"刷新"按钮
   - 获取最新的推荐结果

### 推荐算法说明

推荐系统采用启发式算法，综合考虑：
- 待办事项优先级权重：高=3分，中=2分，低=1分
- 到期紧迫度：越接近到期时间，权重越高
- 标签相关度：与高频标签匹配的内容优先推荐
- 推荐结果按得分从高到低排序

### 使用场景

**场景1：每日开始工作**
- 打开智能推荐，快速了解今日需要关注的任务
- 根据优先级和到期时间合理安排工作

**场景2：项目切换**
- 通过标签筛选，找到与当前项目相关的笔记
- 快速回顾相关知识和背景信息

**场景3：任务管理**
- 查看即将到期的待办事项
- 避免遗漏重要任务

### 空状态处理

如果没有推荐内容，可能是因为：
- 系统中还没有创建笔记或待办事项
- 建议：先创建一些笔记和待办，添加标签和优先级
- 创建后再次点击"刷新"获取推荐

## 预测分析功能

### 功能说明
预测分析帮助您了解：
- 📊 **完成率统计**：近30天的任务完成率
- ⏰ **到期提醒**：未来7天即将到期的任务数量
- 📈 **完成趋势**：未来7天预测的任务完成量

### 使用步骤

1. **选择工具**
   - 在AI助手页面顶部工具栏中，点击"预测分析"按钮（趋势图标）

2. **获取分析**
   - 点击页面底部的"获取预测分析"按钮
   - 系统将分析您的历史数据并生成预测

3. **查看统计数据**
   - 左侧卡片：近30天完成率（百分比）
   - 右侧卡片：未来7天到期数量

4. **查看预测趋势**
   - 未来7天每日预测完成量
   - 可视化进度条展示
   - 预测值基于近7天移动平均

5. **数据不足提示**
   - 如果近30天完成数据少于5个
   - 系统会显示黄色警告提示
   - 预测结果仅供参考

6. **刷新数据**
   - 点击右上角的"刷新"按钮
   - 获取最新的分析结果

### 预测算法说明

预测系统采用简单的时间序列分析：
1. 统计近30天的待办完成情况
2. 计算近7天的日均完成量
3. 使用移动平均作为未来7天的预测值
4. 简单直观，易于理解和验证

### 指标解释

**完成率**
- 计算公式：(近30天已完成数 / 近30天总数) × 100%
- 帮助评估工作效率
- 绿色显示，数值越高越好

**到期数量**
- 未来7天内到期且未完成的待办数量
- 橙色提醒，需要注意合理安排
- 避免任务堆积

**预测完成量**
- 基于历史习惯预测每日完成量
- 紫色到蓝色渐变进度条
- 帮助规划未来工作安排

### 使用场景

**场景1：周计划制定**
- 查看未来7天到期任务数量
- 预测自己的完成能力
- 合理分配新任务

**场景2：工作复盘**
- 查看近30天完成率
- 分析工作效率
- 找出改进空间

**场景3：负荷评估**
- 对比预测完成量和实际到期量
- 判断是否需要调整任务优先级
- 避免过度承诺

### 数据不足处理

如果数据不足（近30天完成数<5），系统会：
- 显示黄色警告提示
- 说明：预测结果仅供参考
- 建议：继续使用系统积累数据
- 仍然显示可用的统计数据

## 常见问题

### Q1: 为什么推荐列表为空？
**A:** 可能原因：
- 系统中笔记或待办事项较少
- 没有设置标签或优先级
- 建议：创建更多内容，添加标签和优先级信息

### Q2: 预测数据显示"数据不足"？
**A:** 这是正常情况：
- 需要近30天至少完成5个待办才能获得准确预测
- 继续使用系统，数据会逐渐积累
- 即使数据不足，仍会显示基本统计

### Q3: 推荐结果不准确？
**A:** 推荐算法会不断优化：
- 确保待办事项设置了合理的优先级和到期时间
- 为笔记添加准确的标签
- 定期使用刷新功能获取最新推荐

### Q4: 如何提高推荐质量？
**A:** 以下做法会改善推荐：
- 为待办设置明确的优先级（高/中/低）
- 设置合理的到期时间
- 为笔记添加相关标签
- 保持标签的一致性和规范性

### Q5: 预测准确吗？
**A:** 预测说明：
- 采用简单的移动平均算法
- 适合短期趋势预测
- 仅供参考，实际情况可能有变化
- 数据越多，预测越准确

### Q6: 多久刷新一次推荐和预测？
**A:** 建议：
- 推荐：每次开始工作时刷新
- 预测：每周刷新一次即可
- 数据有大变化时可以手动刷新
