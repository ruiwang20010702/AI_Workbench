## 演示流程

### 第一部分：智能推荐功能 (5分钟)

#### 1. 导航到AI助手页面
```
步骤：
1. 登录系统
2. 点击顶部导航栏的"AI助手"
3. 或访问：http://localhost:5173/ai-assistant
```

#### 2. 展示工具选项
```
讲解要点：
- AI助手提供7种工具
- 最新添加：智能推荐（灯泡图标）和预测分析（趋势图标）
```

#### 3. 选择智能推荐工具
```
操作：
1. 点击"智能推荐"按钮（黄色灯泡图标）
2. 观察输入区域变化 → 显示"获取智能推荐"按钮
```

#### 4. 获取推荐
```
操作：
1. 点击"获取智能推荐"按钮
2. 观察加载状态（loading动画）
3. 等待1-2秒后显示结果
```

#### 5. 讲解推荐结果
```
讲解内容：

a. 推荐依据（蓝色信息卡片）
   - "高频标签: 项目A, 前端, 后端"
   - "最近笔记: 3条"
   - "待办事项: 7个"
   → 说明：系统分析了您的使用习惯

b. 推荐列表（逐个展示）
   例如第一条：
   - ✅ 类型：待办
   - 📝 标题："修复登录bug"
   - 💡 理由："高优先级，7天内到期"
   - 🎯 优先级：高（红色标签）
   - 📅 到期：2025-11-03

   例如第二条：
   - 📄 类型：笔记
   - 📝 标题："项目A启动会议纪要"
   - 💡 理由："近期高频标签：项目A"

讲解要点：
- 推荐算法考虑优先级、到期时间、标签相关度
- 高优先级且即将到期的任务排在前面
- 与高频标签相关的笔记也会被推荐
```

#### 6. 演示刷新功能
```
操作：
1. 点击右上角的"刷新"按钮
2. 再次显示loading状态
3. 获取最新推荐结果
```

#### 7. 演示空状态（可选）
```
如果需要演示空状态：
1. 暂时删除所有待办和笔记
2. 刷新推荐
3. 显示："暂无推荐内容，请先创建一些笔记或待办事项"
```

### 第二部分：预测分析功能 (5分钟)

#### 1. 切换到预测分析工具
```
操作：
1. 点击"预测分析"按钮（紫色趋势图标）
2. 观察输入区域变化 → 显示"获取预测分析"按钮
```

#### 2. 获取预测
```
操作：
1. 点击"获取预测分析"按钮
2. 观察加载状态
3. 等待1-2秒后显示结果
```

#### 3. 讲解预测结果
```
讲解内容：

a. 数据不足提示（如果显示）
   - 黄色警告卡片
   - "近30天完成数据较少，预测结果仅供参考"
   → 说明：需要积累更多历史数据

b. 统计卡片（两个）
   左侧卡片：
   - 📊 近30天完成率：75.0%
   - ✅ 绿色显示
   → 说明：反映您的工作效率

   右侧卡片：
   - ⏰ 未来7天到期：5
   - 🟠 橙色显示
   → 说明：需要关注的即将到期任务数

c. 未来7天预测图表
   - 7条进度条，每天一条
   - 日期：11/3, 11/4, 11/5, ...
   - 预测完成量：2.5, 2.5, 2.5, ...
   - 渐变色进度条（紫→蓝）
   → 说明：基于近7天移动平均预测

讲解要点：
- 完成率帮助评估工作效率
- 到期数量提醒避免任务堆积
- 预测帮助规划未来工作负荷
```

#### 4. 解释预测算法
```
简要说明：
- 统计近30天的待办完成情况
- 计算近7天的日均完成量
- 使用移动平均预测未来7天
- 简单直观，易于理解
```

#### 5. 演示刷新功能
```
操作：
1. 点击右上角的"刷新"按钮
2. 获取最新预测数据
```

### 第三部分：对比其他工具 (2分钟)

#### 1. 快速切换工具
```
演示不同工具的切换：
- 文本生成 → 输入框 + 类型选择
- 文本改写 → 输入框 + 风格选择
- 智能推荐 → 获取按钮（无需输入）
- 预测分析 → 获取按钮（无需输入）

讲解要点：
- 推荐和预测工具无需用户输入文本
- 直接点击获取按钮即可
- 其他工具需要输入要处理的文本
```

### 第四部分：实际使用场景 (3分钟)

```
演示：
1. 早上到公司，打开AI助手

5. 根据推荐安排今日工作

价值：

- 避免遗漏重要任务

```

```
3. 查看未来7天到期任务数量：5个

5. 判断：本周新增任务不宜超过3个

价值：
- 避免过度承诺
- 合理分配工作负荷
- 提高计划完成率
```

#### 场景3：项目切换
```
演示：
1. 需要切换到新项目
2. 点击"智能推荐"
3. 查看与项目相关标签的笔记推荐
4. 快速找到项目背景资料
5. 开始工作

价值：
- 快速回顾项目信息
- 减少上下文切换成本

```

### 常见问题预案

**Q：推荐结果可以点击跳转吗？**
A：当前版本暂不支持，这是一个很好的建议，已列入后续优化计划。

**Q：可以自定义推荐算法的权重吗？**
A：当前版本使用固定权重，未来考虑提供个性化设置选项。

**Q：预测准确吗？**
A：采用简单的移动平均算法，适合短期趋势预测，仅供参考。数据越多，预测越准确。

**Q：支持导出推荐和预测报告吗？**
A：当前版本暂不支持，这是一个有价值的功能，已列入产品路线图。

**Q：推荐会考虑任务的依赖关系吗？**
A：当前版本主要基于优先级、到期时间和标签，未来会考虑加入任务依赖分析。
