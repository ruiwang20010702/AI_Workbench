### 1. JWT Secret（生产环境必须修改）

```env
JWT_SECRET=your-super-secret-jwt-key-change-in-production-at-least-64-chars
```

**建议**: 使用强随机字符串，至少 64 个字符

生成方法：
```bash
# 使用 Node.js
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"

# 或使用 OpenSSL
openssl rand -hex 64
```

### 2. AI 服务配置（如需使用 AI 功能）

```env
SILICONFLOW_API_KEY=your-siliconflow-api-key
```

**获取方式**: 访问 [SiliconFlow](https://siliconflow.cn) 注册并获取 API Key

### 3. Git 数据源配置（如需周报功能）

```env
GIT_DATASOURCE_ENABLED=true

GITHUB_REPOSITORIES=repo1,repo2
```

**获取 GitHub Token**:
1. 访问 GitHub Settings → Developer settings → Personal access tokens
2. 生成新 token，勾选 `repo` 权限
3. 复制 token 到环境变量

## 🔧 故障排除

### 问题 1: 连接失败

**症状**: `connection refused` 或 `ECONNREFUSED`

**解决方案**:
1. 检查网络连接
2. 验证 Supabase URL 是否正确
3. 确认 API Key 是否有效

### 问题 2: 表不存在

**症状**: `relation "table_name" does not exist`

**解决方案**:
1. 访问 [Supabase SQL Editor](https://app.supabase.com/project/dkczfihkowivzcvsnxpo/sql)
2. 执行相应的迁移 SQL 文件
3. 重新运行测试

### 问题 3: 权限错误

**症状**: `permission denied` 或 `insufficient privileges`

**解决方案**:
1. 确认使用的是 `SUPABASE_SERVICE_ROLE_KEY` 而非 `SUPABASE_ANON_KEY`
2. 检查 Supabase 项目的 RLS (Row Level Security) 策略
