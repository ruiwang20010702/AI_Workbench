## 🔍 如何使用归档文档

### 查找历史实现

如果您想了解某个功能是如何实现的：

1. 在 `已完成任务/` 中找到对应的任务目录
2. 查看 `DESIGN_*.md` 了解设计思路
3. 查看 `FINAL_*.md` 了解最终实现

### 查找测试方法

如果您想了解如何测试某个功能：

1. 查看 `测试报告/` 中的相关文档
2. 查看任务目录中的 `快速测试指南.md` 或 `功能测试指南.md`

### 查找问题解决方案

如果您遇到问题：

1. 查看 `已完成任务/项目诊断/` 中的修复指南
2. 查看各任务的 `TODO_*.md` 了解已知问题
3. 查看 `历史文档/` 中的问题修复说明

## 📝 文档说明

### 任务文档结构

每个任务通常包含以下文档（按执行顺序）：

1. **ALIGNMENT_*.md** - 需求对齐和项目上下文分析
2. **CONSENSUS_*.md** - 需求共识和技术方案确认
3. **DESIGN_*.md** - 系统架构和模块设计
4. **TASK_*.md** - 任务拆分和依赖关系
5. **ACCEPTANCE_*.md** - 验收测试和完成情况
6. **FINAL_*.md** - 最终总结和交付报告
7. **TODO_*.md** - 待办事项和后续优化

### 辅助文档

- **QUICK_START.md** / **快速验证指南.md** - 快速开始使用
- **功能测试指南.md** - 功能测试说明
- **README.md** - 目录说明
