# 多助手系统 UI 布局指南

## 概述

新的多助手系统采用类似 Cherry Studio 的两栏布局设计，提供更好的用户体验。

## 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│                     多助手系统主界面                          │
├──────────────────┬──────────────────────────────────────────┤
│                  │                                          │
│   左侧边栏        │          右侧对话区域                     │
│   (320px)        │          (flex-1)                        │
│                  │                                          │
│  ┌────────────┐  │  ┌────────────────────────────────────┐ │
│  │ Assistants │  │  │        顶部标题栏                   │ │
│  │  Topics    │  │  │  [Bot Icon] Assistant Name         │ │

│                  │  ├────────────────────────────────────┤ │
```

## 组件说明

### 1. 左侧边栏 (Sidebar)

#### 标签页切换
- **Assistants 标签页**: 显示所有助手列表
- **Topics 标签页**: 显示当前助手的对话主题列表

#### 当前助手信息
- 仅在 Topics 标签页显示
- 显示当前选中的助手名称

#### 列表功能
- **Assistants 列表**:
  - 创建新助手按钮
  - 助手列表项（带图标、名称、描述）
  - 悬停显示编辑/删除按钮
  - 默认助手显示星标

- **Topics 列表**:
  - 新建对话按钮
  - 主题列表项（显示标题、消息数、最后更新时间）
  - 悬停显示重命名/删除按钮
  - 支持内联编辑主题标题

### 2. 右侧对话区域 (Chat Area)

#### 顶部标题栏
- 助手图标和名称
- 当前主题标题

#### 消息列表
- 用户消息：右对齐，蓝色背景
- AI 回复：左对齐，灰色背景
- 支持 Markdown 渲染
- 支持代码高亮显示
- 显示时间戳
- AI 消息可复制

#### 输入区域
- 多行文本输入框（自动调整高度）
- 发送按钮
- 快捷键提示：Enter 发送，Shift+Enter 换行

## 交互流程

### 1. 初始化流程
```
加载页面
  ↓
加载助手列表
  ↓
选择默认助手（或第一个助手）
  ↓
加载该助手的主题列表
  ↓
显示空状态或选择第一个主题
```

### 2. 创建对话流程
```
选择助手（Assistants 标签页）
  ↓
自动切换到 Topics 标签页
  ↓
点击"新建对话"按钮
  ↓
创建新主题（默认标题"新对话"）
  ↓
开始对话
```

### 3. 发送消息流程
```
输入消息
  ↓
按 Enter 或点击发送按钮
  ↓
显示用户消息
  ↓
调用后端 API
  ↓
显示 AI 回复
  ↓
更新主题列表（消息数、最后更新时间）
```

## 空状态处理

### 1. 没有选择助手
```
显示欢迎界面
  ↓
"欢迎使用多助手系统"
"请从左侧选择一个助手开始对话"
```

### 2. 没有选择主题
```
显示助手欢迎界面
  ↓
"Hello, I'm {assistant.name}. You can start chatting with me right away"
"请从左侧创建或选择一个对话主题"
```

### 3. 主题没有消息
```
显示对话提示
  ↓
"开始新对话"
"输入消息开始与 {assistant.name} 对话"
```

## 样式特点

### 1. 颜色方案
- 主色调：蓝色 (#2563eb)
- 用户消息背景：蓝色 600
- AI 消息背景：灰色 100
- 悬停效果：灰色 100
- 激活状态：蓝色 50 + 蓝色边框

### 2. 响应式设计
- 左侧边栏固定宽度 320px
- 右侧对话区域自适应
- 消息最大宽度 4xl (56rem)
- 输入框最大高度 8rem

### 3. 动画效果
- 过渡动画：transition-colors
- 悬停效果：hover:bg-*
- 加载动画：animate-spin

## 与 Cherry Studio 的对比

### 相似之处
✅ 两栏布局设计
✅ 左侧助手/主题列表
✅ 右侧对话区域
✅ 标签页切换
✅ 消息气泡样式

### 差异之处
- Cherry Studio 使用 Electron，我们使用 Web
- Cherry Studio 有更多的模型选项
- 我们集成了笔记和待办事项数据源
- 我们支持多数据源查询

## 技术实现

### 组件结构
```
MultiAssistantPage.tsx (主页面)
  ├── AssistantList.tsx (助手列表)
  ├── TopicList.tsx (主题列表)
  ├── ChatArea.tsx (对话区域)
  └── AssistantModal.tsx (助手编辑模态框)
```

### 状态管理
- 使用 React Hooks (useState, useEffect)
- 本地状态管理，无需 Redux
- 自动同步和刷新

### API 调用
- assistantApi: 助手 CRUD
- topicApi: 主题 CRUD
- messageApi: 消息发送和获取
