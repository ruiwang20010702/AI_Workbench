## 🎯 核心功能

### ✅ 已实现功能

1. **两栏布局**
   - 左侧边栏（320px 固定宽度）
   - 右侧对话区域（自适应宽度）
   - 全屏显示，无 Layout 包裹

2. **标签页切换**
   - Assistants 标签页：管理助手
   - Topics 标签页：管理对话主题
   - 自动切换逻辑

3. **助手管理**
   - 创建助手
   - 编辑助手
   - 删除助手
   - 选择助手
   - 默认助手标识

4. **主题管理**
   - 创建主题
   - 重命名主题
   - 删除主题
   - 选择主题
   - 显示消息数和更新时间

5. **对话功能**
   - 发送消息
   - 接收 AI 回复
   - Markdown 渲染
   - 代码高亮
   - 消息复制
   - 自动滚动

6. **空状态处理**
   - 无助手选择提示
   - 无主题选择提示
   - 无消息提示

7. **交互优化**
   - 输入框自动调整高度
   - Enter 发送，Shift+Enter 换行
   - 悬停显示操作按钮
   - 加载状态指示
