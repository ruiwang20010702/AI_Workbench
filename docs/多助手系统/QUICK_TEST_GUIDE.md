# 多助手系统快速测试指南

## 访问地址

🌐 **新版多助手系统**: http://localhost:5173/ai

## 测试步骤

### 1. 基础界面测试

#### 1.1 检查布局
- [ ] 页面显示两栏布局
- [ ] 左侧边栏宽度固定（320px）
- [ ] 右侧对话区域自适应
- [ ] 无滚动条溢出问题

#### 1.2 检查标签页
- [ ] 左侧显示 "Assistants" 和 "Topics" 两个标签
- [ ] 默认选中 "Assistants" 标签
- [ ] 点击标签可以切换
- [ ] 标签切换有视觉反馈（蓝色下划线）

### 2. 助手管理测试

#### 2.1 查看助手列表
- [ ] 左侧显示助手列表
- [ ] 默认助手有星标图标
- [ ] 显示助手名称和描述

#### 2.2 选择助手
- [ ] 点击助手可以选中
- [ ] 选中的助手有蓝色背景
- [ ] 选中助手后自动切换到 "Topics" 标签
- [ ] 显示"当前助手"信息

#### 2.3 创建助手
- [ ] 点击 "+ 创建新助手" 按钮
- [ ] 弹出模态框
- [ ] 填写助手信息：
  - 名称：Test Assistant
  - 描述：测试助手
  - 系统提示词：You are a helpful assistant
  - 模型：deepseek-chat
  - Temperature: 0.7
- [ ] 点击"创建"按钮
- [ ] 新助手出现在列表中

#### 2.4 编辑助手
- [ ] 悬停在助手上显示操作按钮
- [ ] 点击"设置"图标
- [ ] 修改助手信息
- [ ] 点击"保存"
- [ ] 修改生效

#### 2.5 删除助手
- [ ] 悬停在助手上（非默认助手）
- [ ] 点击"删除"图标
- [ ] 确认删除对话框
- [ ] 助手被删除

### 3. 主题管理测试

#### 3.1 查看主题列表
- [ ] 切换到 "Topics" 标签
- [ ] 显示当前助手的主题列表
- [ ] 显示主题标题、消息数、更新时间

#### 3.2 创建主题
- [ ] 点击 "+ 新建对话" 按钮
- [ ] 创建新主题（默认标题"新对话"）
- [ ] 新主题出现在列表顶部
- [ ] 自动选中新主题
- [ ] 右侧显示空对话界面

#### 3.3 选择主题
- [ ] 点击主题可以选中
- [ ] 选中的主题有蓝色背景
- [ ] 右侧显示该主题的消息历史

#### 3.4 重命名主题
- [ ] 悬停在主题上显示操作按钮
- [ ] 点击"编辑"图标
- [ ] 输入框变为可编辑状态
- [ ] 修改标题为"测试对话"
- [ ] 按 Enter 或点击"✓"保存
- [ ] 标题更新成功

#### 3.5 删除主题
- [ ] 悬停在主题上
- [ ] 点击"删除"图标
- [ ] 确认删除对话框
- [ ] 主题被删除

### 4. 对话功能测试

#### 4.1 发送消息
- [ ] 选择一个助手和主题
- [ ] 在输入框输入："你好，请介绍一下你自己"
- [ ] 按 Enter 或点击发送按钮
- [ ] 用户消息显示在右侧（蓝色，右对齐）
- [ ] 显示加载状态
- [ ] AI 回复显示在右侧（灰色，左对齐）

#### 4.2 多行消息
- [ ] 输入框输入文本
- [ ] 按 Shift+Enter 换行
- [ ] 继续输入第二行
- [ ] 按 Enter 发送
- [ ] 消息正确显示多行内容

#### 4.3 Markdown 渲染
- [ ] 发送消息："请用 Markdown 格式写一个列表"
- [ ] AI 回复包含 Markdown 格式
- [ ] 标题、列表、加粗等正确渲染

#### 4.4 代码高亮
- [ ] 发送消息："写一个 Python Hello World 程序"
- [ ] AI 回复包含代码块
- [ ] 代码正确高亮显示

#### 4.5 复制消息
- [ ] 悬停在 AI 回复上
- [ ] 点击"复制"图标
- [ ] 消息内容复制到剪贴板

#### 4.6 自动滚动
- [ ] 发送多条消息
- [ ] 页面自动滚动到最新消息
- [ ] 滚动流畅无卡顿

### 5. 空状态测试

#### 5.1 无助手选择
- [ ] 刷新页面，清除选择
- [ ] 右侧显示："欢迎使用多助手系统"

#### 5.2 无主题选择
- [ ] 选择助手但不选择主题

- [ ] 提示："请从左侧创建或选择一个对话主题"

#### 5.3 主题无消息
- [ ] 创建新主题
- [ ] 右侧显示："开始新对话"
- [ ] 提示："输入消息开始与 {assistant.name} 对话"

### 6. 响应式测试

#### 6.1 窗口缩放

#### 6.2 长文本处理
