## 📋 项目概述

### 项目目标

实现一个类似CherryStudio的多助手对话系统，支持：
- 多个AI助手的创建和管理
- 每个助手独立的对话主题
- 完整的消息历史记录
- 上下文管理和Token控制
- 旧数据迁移兼容

### 核心功能

1. **助手管理**
   - 创建/编辑/删除助手
   - 预设模板（代码助手、写作助手、翻译助手等）
   - 自定义系统提示词、模型参数
   - 默认助手设置

2. **主题管理**
   - 每个助手下创建多个对话主题
   - 主题重命名（内联编辑）
   - 主题删除（单个/批量）
   - 显示消息数和最后活动时间

3. **消息管理**
   - 发送和接收消息
   - Markdown渲染和代码高亮
   - 消息历史分页加载
   - 自动滚动到最新消息

4. **上下文管理**
   - 滑动窗口策略
   - Token数量控制
   - 自动裁剪历史消息

## 📝 使用说明

### 基本流程

1. **创建助手**
   - 点击"创建新助手"按钮
   - 选择预设模板或自定义配置
   - 填写助手名称、描述、系统提示词
   - 配置模型参数（模型、温度、Token数）
   - 保存

2. **开始对话**
   - 选择一个助手
   - 点击"新建对话"创建主题
   - 在输入框输入消息
   - 按Enter发送（Shift+Enter换行）

3. **管理主题**
   - 点击主题名称右侧的编辑按钮重命名
   - 点击删除按钮删除主题
   - 主题会显示消息数和最后活动时间

4. **管理助手**
   - 点击助手右侧的设置按钮编辑
   - 点击删除按钮删除助手（默认助手不可删除）
   - 星标表示默认助手

## ⚠️ 注意事项

### 已知限制

1. **Token限制**: 单次对话受模型Token限制，超长对话会自动裁剪
2. **并发限制**: OpenAI API有速率限制，频繁请求可能被限流
3. **存储限制**: 消息历史会占用数据库空间，建议定期清理

### 最佳实践

1. **合理设置上下文窗口**: 默认10条消息，可根据需要调整
2. **使用预设模板**: 预设模板已优化提示词，效果更好
3. **定期备份数据**: 重要对话建议导出备份
4. **监控Token使用**: 关注API使用量，避免超额

## 📞 技术支持

### 常见问题

**Q: 如何切换到新的多助手系统？**  
A: 访问 `/ai/multi` 路径即可使用新系统，旧系统保留在 `/ai`。

**Q: 旧的对话数据会丢失吗？**  
A: 不会，运行迁移脚本可将旧数据导入新系统。

**Q: 可以同时使用多个OpenAI账号吗？**  
A: 当前版本使用统一的API Key，后续可扩展支持多账号。

**Q: 如何删除所有对话历史？**  
A: 可以批量选择主题删除，或直接清空数据库表。
