# 周报编辑和删除功能测试指南

## 功能说明

本次修复添加了完整的周报编辑和删除功能，包括：

1. **编辑周报**：可以修改周报的标题和内容（Markdown格式）
2. **删除周报**：可以删除不需要的周报（带确认提示）
3. **优化的UI体验**：编辑模式切换流畅，操作反馈及时

## 测试步骤

### 1. 启动开发环境

```bash
# 在项目根目录
npm run dev
```

### 2. 访问周报页面

1. 打开浏览器访问 `http://localhost:5173`
2. 登录系统
3. 导航到"周报管理"页面（路径：`/reports/weekly`）

### 3. 测试编辑功能

#### 3.1 从预览视图编辑

1. 生成一份新周报或点击历史记录中的某份周报
2. 切换到"预览"标签页
3. 点击**"编辑"**按钮（蓝色按钮，带编辑图标）
4. 页面进入编辑模式：
   - 标题变为可编辑的输入框
   - 内容区域变为Markdown编辑器（文本框）
5. 修改标题和内容
6. 点击**"保存"**按钮（蓝色）确认修改，或点击**"取消"**按钮（灰色）放弃修改
7. 验证：
   - ✅ 保存后，预览立即更新显示新内容
   - ✅ 历史记录列表中的标题也已更新
   - ✅ 退出编辑模式，回到预览状态

#### 3.2 编辑模式功能验证

1. 在编辑模式下修改标题
2. 在编辑模式下修改内容（支持Markdown语法）
3. 点击"取消"按钮
4. 验证：
   - ✅ 修改未保存
   - ✅ 内容恢复到原状态
   - ✅ 退出编辑模式

### 4. 测试删除功能

#### 4.1 从预览视图删除

1. 在预览标签页查看一份周报
2. 点击**"删除"**按钮（红色按钮，带垃圾桶图标）
3. 浏览器弹出确认对话框："确定要删除这份周报吗？此操作无法撤销。"
4. 点击"确定"
5. 验证：
   - ✅ 周报被删除
   - ✅ 显示"删除成功"的提示
   - ✅ 自动切换到"生成周报"标签页
   - ✅ 历史记录列表中该周报消失

#### 4.2 从历史记录列表删除

1. 切换到"历史记录"标签页
2. 将鼠标悬停在某个周报项上
3. 右侧出现红色的删除按钮（垃圾桶图标）
4. 点击删除按钮
5. 确认对话框弹出，点击"确定"
6. 验证：
   - ✅ 周报从列表中消失
   - ✅ 显示"删除成功"的提示
   - ✅ 如果正在预览这份周报，预览会被清空

#### 4.3 取消删除

1. 点击删除按钮
2. 在确认对话框中点击"取消"
3. 验证：
   - ✅ 周报未被删除
   - ✅ 列表和预览保持不变

### 5. UI交互测试

#### 5.1 按钮状态验证

**预览视图 - 查看模式**：
- ✅ 显示"编辑"按钮（蓝色）
- ✅ 显示"删除"按钮（红色）
- ✅ 显示"发布"按钮（仅草稿状态，绿色）
- ✅ 显示"AI优化"按钮（仅未优化的周报，紫色）
- ✅ 显示"下载"按钮（蓝色，鼠标悬停显示格式菜单）

**预览视图 - 编辑模式**：
- ✅ 显示"保存"按钮（蓝色，带保存图标）
- ✅ 显示"取消"按钮（灰色，带X图标）
- ✅ 其他操作按钮全部隐藏

**历史记录列表**：
- ✅ 默认不显示删除按钮
- ✅ 鼠标悬停时显示删除按钮
- ✅ 点击周报项（非按钮区域）可预览

#### 5.2 加载状态验证

1. 执行保存操作时
   - ✅ 显示"正在保存..."的加载提示
2. 执行删除操作时
   - ✅ 显示"正在删除..."的加载提示
3. 操作完成后
   - ✅ 显示成功或失败的提示

#### 5.3 错误处理验证

1. 断网情况下尝试保存
   - ✅ 显示"保存失败"的错误提示
2. 断网情况下尝试删除
   - ✅ 显示"删除失败"的错误提示
3. 修改后内容为空时保存
   - ✅ 可以保存（但建议添加验证）

## 已知问题和限制

1. **编辑器功能**：
   - 当前使用简单的文本框编辑Markdown
   - 未来可以升级为功能更丰富的Markdown编辑器（如CodeMirror、Monaco Editor）

2. **实时预览**：
   - 编辑模式下不支持实时预览Markdown渲染结果
   - 需要保存后才能看到渲染效果

3. **撤销功能**：
   - 删除操作不可撤销
   - 建议添加"回收站"功能（归档而非直接删除）

## 技术实现说明

### 前端实现

**新增状态**：
```typescript
const [isEditMode, setIsEditMode] = useState(false);
const [editedTitle, setEditedTitle] = useState('');
const [editedContent, setEditedContent] = useState('');
```

**新增函数**：
- `handleStartEdit()` - 进入编辑模式
- `handleCancelEdit()` - 取消编辑
- `handleSaveEdit()` - 保存编辑
- `handleDelete(id)` - 删除周报

**API调用**：
- `reportService.updateReport(id, { title, content })` - 更新周报
- `reportService.deleteReport(id)` - 删除周报

### 后端API

**已有接口**（无需修改）：
- `PUT /api/reports/weekly/:id` - 更新周报
- `DELETE /api/reports/weekly/:id` - 删除周报

### 涉及文件

- `client/src/pages/reports/WeeklyReportPage.tsx` - 主要修改
- `client/src/services/reportService.ts` - API方法（已存在）
- `server/src/controllers/weeklyReportController.ts` - 控制器（已存在）
- `server/src/routes/weeklyReports.ts` - 路由（已存在）

## 下一步优化建议

1. **Markdown编辑器升级**：
   - 集成更专业的Markdown编辑器
   - 支持实时预览、语法高亮、快捷操作

2. **批量操作**：
   - 支持批量删除周报
   - 支持批量导出

3. **版本历史**：
   - 记录周报的编辑历史
   - 支持回退到历史版本

4. **软删除**：
   - 删除时移至回收站
   - 支持恢复已删除的周报

5. **权限控制**：
   - 已发布的周报限制编辑
   - 或编辑后自动变为草稿状态
