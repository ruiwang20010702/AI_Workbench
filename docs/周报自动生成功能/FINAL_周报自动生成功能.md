## 📚 使用指南

### 基本使用流程

1. **生成周报**
   ```
   导航到 /reports/weekly → 选择"生成周报"Tab
   → 选择时间范围 → 选择模板 → 点击"生成周报"
   ```

2. **预览与编辑**
   ```
   生成完成后自动切换到"预览"Tab
   → 查看HTML渲染结果 → 可选"AI优化"
   ```

3. **发布与导出**
   ```
   点击"发布"按钮（草稿→已发布）
   → 点击"下载"选择格式 → 完成导出
   ```

### 自定义模板

1. **创建模板**
   ```
   点击"模板管理" → "新建模板"
   → 输入模板名称和内容 → 保存
   ```

2. **使用模板变量**
   ```mustache
   {{变量名}}                 # 简单变量
   {{#数组}}...{{/数组}}       # 循环
   {{^条件}}...{{/条件}}       # 条件判断
   ```

3. **设置默认模板**
   ```
   进入模板详情 → 点击"设为默认"
   ```
