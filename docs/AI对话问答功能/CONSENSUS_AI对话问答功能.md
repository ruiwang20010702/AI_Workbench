## 1. 最终需求描述

在AI助手中添加**对话式问答功能**，使AI能够通过自然语言对话回答用户关于个人数据的问题（笔记、项目、待办事项等）。

### 核心功能
1. **智能问答**: 用户可以用自然语言提问，AI理解意图并检索数据生成回答
2. **多轮对话**: 支持上下文保持，可以追问和澄清
3. **对话历史**: 参考ChatGPT，保留最近20条对话记录
4. **数据查询**: 支持查询笔记、项目、待办，单次最多返回20条数据

## 2. 验收标准

### 2.1 功能验收
✅ 用户可以在AI助手中进行对话式问答  
✅ 系统能正确识别问题意图（笔记、项目、待办、统计）  
✅ 系统能检索相关数据并生成准确的自然语言回答  
✅ 支持多轮对话，保持上下文（最近3轮）  
✅ 对话历史正确保存和加载（最多20条）  
✅ 界面设计参考ChatGPT，简洁美观  
✅ AI使用日志正确记录（action_type='assistant_qa'）  

### 2.2 性能验收
✅ 单次问答响应时间 < 5秒  
✅ 对话历史加载时间 < 500ms  
✅ 支持20条对话历史无卡顿  

### 2.3 用户体验验收
✅ 界面友好，操作流畅（参考ChatGPT）  
✅ 回答准确、简洁、有用  
✅ 错误提示清晰明确  
✅ 支持复制回答内容  
✅ 支持清空对话历史  

---

## 3. 技术实现方案

### 3.1 技术约束
- 使用现有的AI服务（SiliconFlow API）
- 不引入新的依赖库
- 保持与现有代码风格一致
- 复用现有的数据模型和API

### 3.2 集成方案
- **前端**: 在现有AIAssistantPage中添加新的对话模式
- **后端**: 新增`POST /api/ai/chat`端点
- **数据存储**: 
  - 对话历史存储在localStorage（最多20条）
  - AI使用记录存储在数据库ai_usage_logs表

### 3.3 界面设计参考
参考ChatGPT的对话界面：
- 左侧：对话历史列表（最多20条）
- 右侧：当前对话区域
- 底部：输入框 + 发送按钮
- 支持新建对话、删除对话、清空历史

## 5. 关键决策记录

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 对话历史保留策略 | 最多20条 | 参考ChatGPT，平衡性能和用户体验 |
| 单次查询数据量 | 最多20条 | 避免回答过长，用户可追问获取更多 |
| 界面设计风格 | 参考ChatGPT | 用户熟悉，体验好 |
| 对话上下文保持 | 最近3轮 | 足够支持追问，避免token消耗过大 |
| 意图识别方式 | AI模型 | 灵活性高，易于扩展 |
| 对话存储位置 | localStorage | 快速加载，无需额外表 |
