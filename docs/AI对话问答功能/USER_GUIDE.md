# AI智能问答 - 用户使用指南

**版本**: 1.0.0  
**更新时间**: 2025-11-02

---

## 📖 功能介绍

AI智能问答是AI Workbench的核心功能之一，让您可以通过自然语言对话的方式，快速查询和管理您的笔记、项目和待办事项。

### ✨ 主要特性

- 🤖 **智能理解**：AI能理解您的自然语言问题，无需记忆复杂的命令
- 💬 **多轮对话**：支持上下文保持，可以连续追问
- 📚 **全面查询**：查询笔记、项目、待办事项和统计信息
- 🎨 **ChatGPT风格**：熟悉的对话界面，简洁美观
- 📝 **对话历史**：自动保存最近20条对话，随时查看

---

## 🚀 快速开始

### 1. 进入智能问答

1. 登录AI Workbench
2. 点击左侧导航栏的"AI助手"
3. 在工具栏中选择"智能问答"

### 2. 开始对话

#### 方式一：自动创建对话
- 如果是第一次使用，系统会自动创建一个新对话
- 直接在输入框输入问题即可

#### 方式二：手动创建对话
- 点击左侧的"新建对话"按钮
- 在输入框输入您的问题

### 3. 发送问题

- **方法1**：输入问题后，点击"发送"按钮
- **方法2**：输入问题后，按`Enter`键（推荐）
- **换行**：需要换行时，按`Shift + Enter`

## 🎯 高级技巧

### 1. 多轮对话

AI会记住最近3轮对话的上下文，您可以连续追问：

```
用户: 我最近的项目是什么？
AI: 您最近的项目有：1. AI Workbench...

用户: 第一个项目的详细信息
AI: AI Workbench项目的详细信息如下：...

用户: 这个项目的进度如何？
AI: AI Workbench项目目前进度为75%...
```

### 2. 时间范围查询

支持的时间范围：
- **今天**: "今天的待办"
- **本周**: "本周完成的任务"
- **本月**: "本月的项目"
- **最近**: "最近的笔记"（默认7天）

### 3. 条件过滤

支持的过滤条件：
- **优先级**: 高、中、低
- **状态**: 进行中、已完成、未开始等
- **标签**: 指定标签名称
- **关键词**: 任意关键词搜索

### 4. 组合查询

可以组合多个条件：
- "本周高优先级的待办事项"
- "进行中的高优先级项目"
- "标签为'学习'的最近笔记"

## 📚 对话管理

### 对话列表

左侧显示您的对话历史：
- **对话标题**: 自动从第一条消息生成
- **消息数量**: 显示该对话的消息总数
- **更新时间**: 最后一次更新的时间

### 切换对话

- 点击左侧列表中的任意对话即可切换
- 当前对话会高亮显示

### 删除对话

- 鼠标悬停在对话上
- 点击右侧的垃圾桶图标
- 对话将被删除（无法恢复）

### 清空历史

- 点击左下角的"清空历史"按钮
- 确认后，所有对话将被清空（无法恢复）

### 对话限制

- 最多保留**20条对话**
- 超过20条时，最旧的对话会自动删除
- 每条对话保留最近**3轮**（6条消息）作为上下文

## ⚠️ 注意事项

### 1. 数据访问

- AI只能访问**您自己的数据**
- 无法访问其他用户的笔记、项目或待办
- 确保您已登录

### 2. 查询限制

- 单次查询最多返回**20条数据**
- 如果数据较多，AI会优先返回最相关的
- 可以通过追问获取更多信息

### 3. 问题长度

- 问题最多**500字**
- 超过限制会提示错误
- 建议简洁明确地提问

### 4. 响应时间

- 通常**3-5秒**内得到回答
- 复杂查询可能需要更长时间
- 请耐心等待，不要重复发送

### 5. 数据准确性

- AI回答基于您的实际数据
- 不会编造不存在的信息
- 如果没有找到数据，会友好提示

## 🐛 常见问题

### Q1: AI没有回答我的问题？

**可能原因**:
- 网络连接问题
- API密钥未配置或无效
- 服务器错误

**解决方法**:
1. 检查网络连接
2. 检查AI配置（设置页面）
3. 刷新页面重试
4. 联系管理员

### Q2: AI回答不准确？

**可能原因**:
- 问题表述不够清晰
- 数据不完整
- 意图识别错误

**解决方法**:
1. 换个方式提问
2. 提供更多上下文
3. 使用更具体的关键词
4. 检查数据是否存在

### Q3: 对话历史丢失了？

**可能原因**:
- 清空了浏览器缓存
- 手动清空了对话历史
- 超过20条被自动删除

**解决方法**:
- 对话历史存储在本地浏览器
- 清空缓存会导致丢失
- 重要对话建议手动记录

### Q4: 无法发送消息？

**可能原因**:
- 输入框为空
- 正在加载中
- 未登录

**解决方法**:
1. 确保输入了内容
2. 等待上一条消息处理完成
3. 检查登录状态

### Q5: 移动端体验不好？

**说明**:
- 当前主要针对桌面端优化
- 移动端功能正常但体验待优化
- 建议使用桌面浏览器
