## ⚠️ 立即需要处理的事项

### 1. 配置AI API密钥 ⭐⭐⭐

**重要性**: 🔴 必需  
**说明**: 功能已实现，但需要配置有效的API密钥才能正常工作

**操作步骤**:

#### 方式一：通过前端配置（推荐）
1. 登录AI Workbench
2. 进入"设置"页面
3. 找到"AI配置"部分
4. 输入您的SiliconFlow API密钥
5. 选择默认模型（推荐：`moonshotai/Kimi-K2-Instruct-0905`）
6. 保存配置

#### 方式二：通过环境变量配置
1. 编辑 `server/.env` 文件
2. 添加或修改：
   ```env
   SILICONFLOW_API_KEY=your-actual-api-key-here
   SILICONFLOW_API_BASE_URL=https://api.siliconflow.cn/v1
   ```
3. 重启后端服务

**获取API密钥**:
- 访问 https://siliconflow.cn
- 注册账号并获取API密钥
- 或使用其他兼容的AI服务（OpenAI、Claude等）

**验证配置**:
```bash
# 测试API密钥是否有效
curl -X POST http://localhost:3000/api/ai/chat \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{"question": "你好"}'
```
